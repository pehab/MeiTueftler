# MeiTüftler graphics

Built-in image generation, using the existing MeiLists icon as the MeiApps family style reference.

Icon prompt: cheerful glossy yellow inventor with teal safety goggles, wooden ramp, orange marble and one gear; dark warm outlines, teal backdrop, highlights and clean sparkles, no text, full-bleed square.

Feature graphic prompt: same inventor in a warm marble workshop with ramp, trampoline, fan, red switch and gate; exact German text “MeiTüftler” and “Baue. Teste. Staune.”; wide promotional illustration, no invented interface or store badges.

The icon has separate 512px store, launcher and adaptive assets. Feature art is proportionally fitted to the required 1024×500 canvas. Screenshot cards are composed from actual emulator captures; interface content is kept unchanged.
